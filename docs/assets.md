# Visual assets

The original user-provided mockups in docs/ are preserved. Production UI elements are HTML/CSS; no entire mockup is embedded as the interface.

Three original raster images were generated using the built-in image generation tool for this implementation and saved under static/images/:

- blue-hour.png: portrait blue twilight concert photo, guitarist silhouette, blue spotlights; exact title BLUE HOUR LIVE; no UI or date.
- open-air.png: portrait warm sunset riverside festival with amber lights and audience; exact title OPEN AIR SESSION; no UI or date.
- hero.png: wide navy concert photo, performer in right third, left negative space for HTML headline; no text or UI.

The common prompt direction was premium editorial concert photography matching the supplied blue/teal ticket-service concept. These files are assets for fictional performances, not photographs of the named fictional events. All Korean UI text remains selectable HTML. Typography uses local system fonts and requires no external font request.
