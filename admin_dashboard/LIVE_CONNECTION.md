# 공개 지표 연결

## 관리자 화면 정리 결과

실제 화면과 시안의 공통 파일을 `templates/monitor_user_flow.html`, `static/monitor_navigation.js`, `static/monitor_common.css`로 정리했다. 기존 이름의 중복 파일은 남기지 않았다. 조회·계약 검사·표시 변환·페이지 연결은 `user_flow/`의 기존 역할 분리를 유지한다.

예매율 시계열에서 성공·시작·진행 중 시도 수를 확인할 수 있다. 분모 없는 구간과 미관측 구간은 선을 끊고 하단 표식을 선택해 구분한다. 하단 표식의 위치는 수치 0을 의미하지 않는다. 실제 0은 관측된 수치로 표시된다. 실제 화면의 샘플 표현과 인원 단위를 정리했고, 현재 파이프라인의 실행·검증 실패 상태는 조회하지 않는다는 제한을 화면에 명시했다.

이번 작업은 DB 공개·연결이 준비되었다는 전제의 관리자 코드 검증이다. DB 브랜치는 같은 DB 안에 두 공개 뷰, 동일 버전 문서, 읽기 계정과 권한을 준비하고 기존 관리자 URI에 그 대상을 연결해야 한다. 지표 DB 이름을 관리자 코드에서 고정하지 않는다.

관리자·지정 QA MongoDB 회귀 검사는 40개가 통과했다. 브라우저 검사는 기존 인증 경로 위에서 로컬 템플릿으로 렌더링한 격리 문서와 로컬 정적 파일을 사용했다. 7단계·취소·기타 단계·진행 중 시도·미관측·분모 없음·키보드·1600px 및 390px 화면·시안과 기존 조회 경로를 확인했다. 운영 DB 정상 연결을 검증한 결과가 아니다. 배포 이미지와 컨테이너는 이번 작업에서 갱신하지 않았다.

## 접속 경로와 보존

- 실제 공개 지표: `http://localhost:8000/admin/`
- 기존 이벤트 조회: `http://localhost:8000/admin/db`
- 고정 시안: `http://localhost:8000/admin/preview`

기존 `/db` 별칭의 이벤트 조회 경로를 유지하고 `/`를 공개 지표 화면으로 연결했다. 새 화면 상단의 ‘기존 이벤트 조회’에서 이전 기능에 접근할 수 있다. 기존 정제 이벤트 리더·실제 이벤트 템플릿·QA 코드는 수정하지 않았다.

## 조회와 화면

기존 `TICKET_GUARD_ADMIN_MONGO_URI`의 기본 DB에서 `flow_read_current`와 `flow_read_series`만 읽는다. 내부 저장 컬렉션·원본 DB를 우회 조회하지 않는다. 최신·시계열·내부 문서 식별자가 모두 같은 공개 버전인지 확인하며 최대 세 번 조회한다. 범위 목록도 공개 뷰의 식별자로만 구성한다.

사용자 흐름의 다섯 지표를 연결했다.

| 지표 | 사용 값 |
|---|---|
| 체류 평균·중앙값·표본 수 | 노드의 `dwell` |
| 단계별 현재 접속 | 노드의 `current` |
| 단계별 전환율 | 연결의 분자·분모·비율 |
| 예매율 | 최신 `booking`과 시작 구간별 시계열 |
| 동시 접속 | 최신 `current`와 관측 시각별 시계열 |

집계 단위가 `browser_session`이므로 실제 화면은 ‘브라우저 세션’과 ‘개’로 표시한다. 로그인 사용자 수로 바꾸지 않는다. 저장된 평균·중앙값·비율을 다시 집계하지 않으며 시계열은 조회 당시 최근 12시간만 표시한다. 표본 부재·결측·0을 구분한다. 시간은 한국 시각으로 변환하며 기준·집계 범위·공개 시각을 제공한다. 임의의 지연 판정 기준이나 자동 갱신은 없다.

그래프는 단계 식별자와 저장된 표시 순서를 사용하며 6개 노드나 배열상 인접 관계에 의존하지 않는다. 기타·새로운 단계와 정상 진행·역방향·재시도·취소 연결을 지원한다. 없는 연결을 만들어 넣지 않는다. 시계열 선은 저장된 모든 표본을 사용하고 축 눈금과 선택용 표본 요소 수만 제한한다.

네트워크·이상탐지는 실제 집계 계약이 미연결이므로 안내와 시안 이동 링크만 제공한다. 실제 화면에서는 샘플 자료를 호출하지 않는다.

## 주요 구현 파일

- `src/ticket_guard_admin/user_flow/contracts.py`: 필드·버전·수치·참조·시각 검사와 안전한 오류.
- `src/ticket_guard_admin/user_flow/reader.py`: 기존 연결의 공개 뷰 조회와 버전 재조회.
- `src/ticket_guard_admin/user_flow/presentation.py`: 표시 단위·한국 시각·12시간 범위 변환.
- `src/ticket_guard_admin/user_flow/pages.py`: 실제 페이지의 결과·오류 상태 연결.
- `templates/monitor_live.html`, `monitor_unconnected.html`: 실제 화면과 미연결 안내.
- `templates/monitor_navigation.html`, `monitor_user_flow.html`: 시안과 실제 화면의 공통 탐색·흐름 표시.
- `static/monitor_flow.js`, `monitor_charts.js`, `monitor_navigation.js`: 식별자 기반 그래프·시계열·관점 전환.
- `tests/test_published_flow.py`: 공개 문서·오류·버전·단위·결측·페이지 검사.
- `tests/render_published_fixture.py`, `check_published_browser.cjs`: 운영 DB에 쓰지 않는 정상 화면 브라우저 검사.

## 현재 실제 연결 상태

2026-11-12 확인 시 현재 관리자 컨테이너의 연결 대상 DB 이름은 `ticketguard`였다. MongoDB가 인증 오류 18을 반환해 공개 뷰 존재 여부와 실제 결과 적재 여부는 확인하지 못했다. 계정·인증 DB·비밀번호·연결 대상의 정합성을 확인해야 한다. URI와 자격 증명은 문서·화면에 기록하지 않았다.

실제 `/admin/`에서는 인증 실패 안내가 나타나는 것을 확인했다. 단순히 데이터가 없다고 판단하거나 정상값으로 표시하지 않는다. 기존 연결 변수의 자격 증명과 대상 DB가 올바르고 공개 뷰를 읽을 수 있어야 실제 운영 수치가 나타난다. 새 환경변수·계정·뷰·권한·시험 운영 문서를 추가하지 않았다.

## 검증 범위

관리자·지정 MongoDB 회귀 검사에는 읽기 경계, 계약 형식, 버전 변경·재조회, 반복 불일치, 범위, 권한·인증·연결 오류, 표본 없음과 0, 최근 12시간·한국 시각, 안전한 문자열 출력, 실제 화면의 샘플 호출 금지, 시안의 DB 접근 금지를 포함했다. 기존 이벤트 조회 회귀 검사는 보존된 `/db` 주소에서 같은 내용을 확인한다.

기존 게이트웨이의 관리자 인증을 통해 실제 인증 실패 상태, 세 관점, 미연결 안내, 뒤로 가기, 시안·기존 이벤트 화면 보존을 확인했다. 정상 그래프는 메모리의 공개 문서를 실제 페이지 코드로 렌더링한 격리 자료로 검사했다. 브라우저가 해당 문서를 읽도록 시험에서만 응답을 대체했으며 운영 DB에 적재하지 않았다. 정상 화면의 운영 DB 연동 성공을 의미하지 않는다.

일곱 단계, 기타 단계의 표본 없음, 0개, 역방향·재시도·취소, 키보드 선택, 1600px·390px 화면을 확인했다. 캡처는 `output/admin-live/`이며 `actual-state.png`는 실제 연결 상태, `isolated-published-*.png`는 격리 정상 자료다.

관리자 이미지와 관리자 컨테이너만 갱신했다. 새 공개 포트·운영 데이터 쓰기·다른 서비스 재시작은 없었다. 기존 사용자 변경·작성자 주석을 보존했으며 커밋·푸시하지 않았다.
